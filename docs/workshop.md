# Steam Workshop path

Workshop publishing is a later distribution step, not a prerequisite for
testing the prototype.

## What we need from the creator

- a Steam installation of Rocket League for Workshop testing;
- a Steam account that can access the Rocket League Community Hub and publish
  Workshop content;
- the Rocket League Workshop Uploader/tooling appropriate to the current game
  version;
- a packaged custom map, preview image, title, description, and license notes.

No permission is needed to run the local simulator or to test an exported map
offline. Publishing will require the user's Steam session and may require
accepting Steam Workshop terms in the uploader.

## Publishing order

1. Validate the asset in a local custom map.
2. Package the map and create a clean thumbnail.
3. Log into the creator's Steam account through the official uploader.
4. Publish as a private/unlisted test item first, if the uploader supports it.
5. Subscribe from a second account or machine and test a clean install.
6. Publish publicly only after the collision and goal-scoring checks pass.

Check the game's official support and Workshop documentation for current
compatibility, publishing requirements, and permitted use. This repository has
not completed a Workshop upload or a game compatibility test.
